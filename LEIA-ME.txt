RADAR IMOBILIÁRIO — VERSÃO PARA NETLIFY

COMO PUBLICAR COM PESQUISAS FUNCIONANDO:
1. Coloque estes arquivos em um repositório PRIVADO no GitHub (mantenha a estrutura de pastas).
2. No https://app.netlify.com/, selecione Add new project > Import an existing project e conecte o repositório GitHub.
3. Deixe o comando de build vazio; diretório de publicação: . ; functions: netlify/functions.
4. Na Netlify, abra Project configuration > Environment variables e crie BRAVE_API_KEY com sua chave pessoal da Brave Search API.
5. Faça o deploy. Abra o endereço .netlify.app gerado e clique em 'Pesquisar agora'.
6. Após adicionar a variável, execute novo deploy se for necessário.

IMPORTANTE: Upload por arrastar/soltar pode exibir a interface, mas não é uma forma confiável de publicar a função de busca. Para pesquisas online, faça implantação via Git ou Netlify CLI.

A API Brave pode ter custos e exige cadastro; verifique os preços e limites atuais diretamente no fornecedor.
Nenhuma pesquisa pública comprova volume efetivo de vendas. Para vendas confirmadas, importe registros reais na aba 'Vendas confirmadas'. Dados importados ficam no navegador local e não são sincronizados entre Mac e iPhone.

Não coloque a chave da Brave em arquivos públicos, no GitHub ou no HTML.
